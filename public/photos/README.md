# Photos

Drop your images here with these exact names:

| File | Used in | Figma size |
| --- | --- | --- |
| `portrait.jpg` | Panel 1 (left) | 429 × 567 |
| `portrait-wide.jpg` | Panel 3 (right) | 741 × 770 |

Until a file exists, the slot renders a hatched placeholder — no broken images.
Any other filename works too; just update the paths in `lib/content.ts`.
